# STEMMate A3 – Walkthrough Script (target 5 minutes, allowed 4–6)

Record the screen only (no faces). Use browser zoom at 125% so text is readable in the video. Reset demo data first. Suggested split: two or three team members narrate different parts. Say your role, not your full name, if you prefer.

| Time | On screen | Narration (read naturally) |
|---|---|---|
| 0:00–0:30 | Sign-in page, footer version | "This is STEMMate Namibia, prototype version 1.1, built by [team] for adult STEM facilitators working with intermittent internet, costly data and shared, low-specification devices. All content is synthetic. We will show two priority workflows and a failure and recovery workflow." |
| 0:30–0:50 | Enter wrong PIN, then 1234 | "The device is shared, so each facilitator signs in with a profile and PIN. Wrong PINs give a clear message, and the profile pauses after five attempts. That is our local access check for SR-01." |
| 0:50–1:50 | Find: set Chemistry + Junior secondary → no results → Remove filter → Physics, bottles/straws/water/tape | "Workflow 1 is finding and saving an activity. The list is stored on the device, so filtering works offline. With no matches, we show no activity cards at all, so nobody can select a missing activity. That fixes our A2 feedback. You can remove one filter at a time instead." |
| 1:50–2:40 | Open Bottle hydraulic lift; show size; test controls → Storage full → Save → error → turn off → Retry save → progress → saved | "The download size is shown before saving because data is costly. With a full device we explain how much space is needed, and Retry save runs the same save again. Here the save succeeds with a visible progress bar, and the status says 'Saved on this device' in words and with an icon, not only in colour." |
| 2:40–3:30 | Set Offline; Plan a session; show autosave; clear the date; submit → error summary → click link → fix → queue | "Workflow 2 is planning offline. Every change saves itself on the device, with the time shown. Plan materials are part of the plan and the sync payload. If something is missing, an error summary takes focus and each link jumps to the field. Learner data is limited to a number, and names and contact details are blocked." |
| 3:30–4:40 | Outbox queued → tick Conflict + Fail next upload → Online → Conflict → Review → submit without choice → choose → upload fails → Retry now → Synced | "Workflow 3 is recovery. Offline, the plan waits safely in the outbox. When the connection returns it syncs automatically. Here the coordinator changed the same plan, so we show both versions and ask for a choice on each difference. Nothing is overwritten silently. The merged plan is saved on the device before uploading, so when this upload fails we say it is safe and offer Retry now. Retrying syncs it." |
| 4:40–5:10 | Keyboard only: Tab from top shows skip link; Device page text size and data saver | "Accessibility targets WCAG 2.2 AA. Everything works by keyboard, there is a skip link, the design reflows at 320 pixels, and there are text-size and data-saver options. Automated checks found 0 violations in 19 screen states after we fixed four issues from version 1.0." |
| 5:10–5:30 | Sign out and lock | "Signing out locks the profile, so the next person cannot see these plans. Our evaluation with classmates led to [two changes in v1.2]. The link, repository and version are in our PDF. Thank you." |

Checklist before recording: demo data reset, zoom set, notifications off, test controls panel collapsed until needed, and version visible in the footer.
